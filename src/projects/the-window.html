The Window


Time2025

Team Member
Yetong Xin

Program
Harvard GSD VIS 2314: Responsive Environments






The Window is an interactive projection installation that explores the interplay between physical interaction and AI-generated virtual environments. This project transforms an intimate, enclosed bedroom setting into a contemplative, immersive sanctuary.

By linking a tangible rotary interface to a generative AI model, the installation enables users to physically manipulate prompts that influence real-time visual projections. Drawing inspiration from the magical realism of Howl’s Moving Castle, particularly the enchanted doorknob that shifts worlds, The Window blurs the boundary between the physical and the digital, the interior and the exterior.

The system leverages Stable Diffusion and TouchDesigner to produce responsive imagery that reflects users’ inputs, guided through a cam-and-spring mechanical design. Ultimately, the project reimagines the role of domestic space, using interactive technology to foster deeper emotional and perceptual engagement with artificial environments.
