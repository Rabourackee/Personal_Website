This project is a revival of the original TRANSFORM from the Tangible Media Group. 

While the original TRANSFORM occupies the scale of a large desk, Mini TRANSFORM reimagines the system as a compact, hand-held device. It is designed to be graspable and playable, bringing shape-changing interaction into a more personal and tactile scale.

We re-engineered the mechanical structure of each pixel and minimized the overall architecture to achieve the smallest possible form factor while preserving movement and responsiveness.

Mini TRANSFORM opens new possibilities, particularly for embedding AI agents directly into physical, shape-changing interfaces.

This project is ongoing.
